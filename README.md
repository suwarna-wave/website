
# 🌐 Personal Portfolio Website  
**[Live Demo](https://suwarna-wave.github.io/website/)**  

This is my personal portfolio website showcasing my journey as an enthusiastic space-robotics learner, undergraduate engineer, and community leader. It highlights my experiences in web development, astronomy, robotics, and leadership roles in various organizations.  

---

## 🚀 Features  
- **Responsive Design:** Ensures optimal viewing on all devices.  
- **Dynamic UI Elements:** Interactive and engaging user interface.  
- **Detailed Sections:**  
  - **About Me:** Overview of my background and interests.  
  - **Resume:** Educational qualifications and professional experiences.  
  - **Portfolio:** Projects and contributions showcasing my skills.  
  - **Blog:** Insights and thoughts on technology, astronomy, and more.  
  - **Contact:** Easy way to reach out for collaborations.

## ⚙️ Getting Started  
### Prerequisites  
Make sure you have **Git** and a modern web browser installed.  

### Installation  
Clone the repository:  
```bash
git clone https://github.com/suwarna-wave/website.git
```  
Navigate to the project directory and open `index.html` in your browser:  
```bash
cd website  
open index.html  
```  

---

## 🚀 Deployment  
This website is deployed using **GitHub Pages**. To deploy your own version:  
1. Fork the repository.  
2. Go to **Settings > Pages** in your forked repository.  
3. Select the main branch as the source.  
4. Your website will be live at `https://<your-username>.github.io/website/`.
